# Release Walkthrough Videos

These walkthroughs show accepted alpha release recordings. Each recording must
show a real, replayable workflow against a local WebHDP Docker instance. Short
status checks and generated route tours are not included in this public guide.

## Guide Groups

| Guide | Use It For |
|---|---|
| [Installation And Setup](installation_and_setup.md) | Clone, Docker startup, health checks, and first-run setup. |
| [Publication And Processing](publication_and_processing.md) | Upload, MSF preflight, pipeline execution, records, provenance, and persisted EDM evidence. |
| [Metadata And Retrieval](metadata_and_retrieval.md) | EDM template validation, Zenodo credential setup, OAI harvest, and account retrieval. |
| [Public Records And Operations](public_records_and_operations.md) | Public record pages, oEmbed, cloud mirror checks, and admin troubleshooting. |
| [Components And Development](components_and_development.md) | HDP Component Playground and component test verification. |

## Quality Bar

Accepted walkthroughs should:

- start from a recognizable WebHDP state
- use local or synthetic data that can be repeated by other users
- show the action, result, and verification point
- keep credentials, private endpoints, and personal filesystem paths hidden
- include captions when subtitle files are available
- avoid placeholder clips that only move through screens without a workflow

## Suggested Viewing Order

1. Installation And Setup
2. Publication And Processing
3. Metadata And Retrieval
4. Public Records And Operations
5. Components And Development, when component execution is part of the demo
