# External Standards Links

WebHDP generates and validates metadata against public cultural-heritage standards, but the public alpha repository does not vendor full copies of external prose documentation.

Use the official upstream documentation for normative guidance:

| Standard or service | Official source |
| --- | --- |
| Europeana Data Model and EDM resources | https://github.com/europeana/edm-resources |
| Europeana EDM XSD schemas for Metis | https://github.com/europeana/metis-schema/tree/v15/src/main/resources/schema_xsds |
| Europeana Publishing Framework and EDM guidance | https://europeana.atlassian.net/wiki/spaces/EF/ |
| IIIF Presentation API | https://iiif.io/api/presentation/ |
| METS | https://www.loc.gov/standards/mets/ |
| MODS | https://www.loc.gov/standards/mods/ |
| Zenodo REST API | https://developers.zenodo.org/ |

Runtime validation schemas that WebHDP needs offline remain in the repository with provenance recorded in `THIRD_PARTY_NOTICES.md`.
